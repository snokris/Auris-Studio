Speech Text Processing
Converts digits, dates, and currency into spoken form (e.g. “2345” → “two thousand three hundred forty-five”). English/Chinese/Japanese: install wetext on Windows (or WeTextProcessing on Linux/macOS). Other languages (including Hungarian) use num2words for integers. Changing this creates new audio cache entries for affected segments.
Output Defaults
When on, no per-chapter files are written at all: every chapter is rendered first, then joined and encoded once, with the subtitles retimed to match.
Gentle EQ, compression and two-pass EBU R128 loudness matching (−19 LUFS) per chapter, via ffmpeg. Gives audiobook-standard, even loudness; off keeps the raw engine output. If ffmpeg fails, the unmastered audio is exported and the export still succeeds.
MP3 Encoding
—
Narration is mostly speech separated by short silences. VBR spends almost nothing on those pauses, so at the same perceived quality it produces a noticeably smaller file than CBR.
libmp3lame -q:a. The source is 24 kHz mono, so these land far below the numbers you would need for music. 7 is clean for a single narrator voice and about a quarter the size of the old fixed 160 kbps output.
24 kHz mono is MPEG-2 Layer III, whose ceiling is 160 kbps — a higher request is silently clamped by the encoder.
Spoken Pauses
Seconds of silence between two ordinary segments (default 0.35).
Slightly longer beat when a new speaker takes over (default 0.55).
An ellipsis is a deliberate trailing-off pause (default 1.5). These lengths apply to both the exported audio and in-app playback, and the subtitle timings follow them automatically.
A human reader takes a bigger breath where a paragraph ends (default 0.85). Overrides the sentence and dialogue pauses at real paragraph boundaries.
Silence inserted where two chapters meet inside a joined file (default 2.0). Longer than any in-chapter pause, so the break stays audible.

Audio Cache

Generated speech is cached in reader/audio_cache so nothing is ever synthesized twice — exports resume from it after an interruption. Files no longer referenced by any book (deleted books, old voice or quality settings) can be removed safely. Files newer than one hour are always kept.
